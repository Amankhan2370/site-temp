# Education logos

- **northeastern-logo.svg** — Full Northeastern University wordmark.
- **northeastern-emblem.svg** — Emblem only (the "N") for card background; university name is shown as text on the card.
- **osmania-logo.svg** — Emblem only (OU crest) for card background; university name is shown as text on the card. If it doesn’t load (e.g. hotlink block), download https://www.osmania.ac.in/images/logo.png and save as `osmania-logo.png` here, then update the Osmania card background in `styles.css` to `url("images/osmania-logo.png")`.

# Experience logos

- **balanx-logo.png** — Balanx-Bio logo; used as background on the first experience card.
- **TESSCO** — Card uses `https://www.tessco.com/medias/tessco-logo-white.svg` (may be faint on light background). For a clearer purple logo: save the TESSCO logo (e.g. from Business Wire) as `images/tessco-logo.png`, then in `styles.css` set `.timeline-content--tessco` to `background-image: url("images/tessco-logo.png");`.
