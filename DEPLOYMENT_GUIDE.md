# 🚀 How to Host Your Portfolio on LinkedIn - Complete Guide

## ⚡ Option 1: Netlify (Easiest & Fastest - Recommended)

**Time: 2-3 minutes | Free Forever | Custom Domain Available**

### Step-by-Step:

1. **Go to Netlify:**
   - Visit: https://www.netlify.com
   - Click "Sign up" (use GitHub, Google, or Email)

2. **Deploy Your Site:**
   - Drag and drop your entire `portfolio` folder onto the Netlify dashboard
   - OR click "Add new site" → "Deploy manually" → Choose folder
   - Wait 10-20 seconds for deployment

3. **Get Your URL:**
   - Netlify gives you a URL like: `https://random-name-12345.netlify.app`
   - Your site is **LIVE** instantly! ✅

4. **Customize Domain (Optional):**
   - Click "Site settings" → "Change site name"
   - Change to: `amankhan-portfolio.netlify.app` or similar
   - Your new URL: `https://amankhan-portfolio.netlify.app`

5. **Add to LinkedIn:**
   - Go to your LinkedIn profile → Click "Edit profile"
   - Find "Contact info" section → Click "Edit"
   - Under "Website", click "Add website"
   - Paste your Netlify URL (e.g., `https://amankhan-portfolio.netlify.app`)
   - Label: "Portfolio" or "Personal Website"
   - Click "Save"

**Done! Your portfolio is now permanently hosted and linked on LinkedIn! 🎉**

## 📦 Option 2: GitHub Pages (Best for Developers)

**Time: 5-10 minutes | Free Forever | Professional URL**

### Step-by-Step:

1. **Create GitHub Account:**
   - Go to: https://github.com
   - Sign up (if you don't have an account)

2. **Create New Repository:**
   - Click "+" icon → "New repository"
   - Name it: `portfolio` (or `amankhan-portfolio`)
   - Select "Public"
   - Check "Add a README file" (optional)
   - Click "Create repository"

3. **Upload Your Files:**
   - In your new repository, click "uploading an existing file"
   - Drag ALL your portfolio files:
     - `index.html`
     - `styles.css`
     - `script.js`
     - `profile-image.jpg`
     - `README.md`
   - Scroll down → Type commit message: "Initial portfolio deployment"
   - Click "Commit changes"

4. **Enable GitHub Pages:**
   - Click "Settings" tab (top right)
   - Scroll down to "Pages" (left sidebar)
   - Under "Source", select "Deploy from a branch"
   - Branch: `main`
   - Folder: `/ (root)`
   - Click "Save"

5. **Get Your URL:**
   - Your site will be live at: `https://yourusername.github.io/portfolio`
   - It takes 1-2 minutes to deploy
   - Refresh the Pages settings page to see the URL

6. **Add to LinkedIn:**
   - Copy your GitHub Pages URL
   - LinkedIn Profile → Edit → Contact info → Add website
   - Paste URL → Save

**Done! 🎉**

## ⚡ Option 3: Vercel (Developer-Friendly)

**Time: 3-5 minutes | Free Forever**

### Step-by-Step:

1. **Go to Vercel:**
   - Visit: https://vercel.com
   - Click "Sign Up" (use GitHub for easiest setup)

2. **Deploy:**
   - Click "Add New..." → "Project"
   - Import from GitHub (if connected) OR
   - Drag and drop your portfolio folder

3. **Get URL:**
   - Vercel gives you: `https://portfolio-yourname.vercel.app`

4. **Add to LinkedIn:**
   - Same process as above!

## ❓ Troubleshooting

**Portfolio not showing?**
- Make sure all files are uploaded
- Check that `index.html` is in the root folder
- Verify `profile-image.jpg` exists

**Image not displaying?**
- Ensure `profile-image.jpg` is uploaded
- Check file name matches exactly (case-sensitive)

**LinkedIn not loading the link?**
- Make sure URL starts with `https://`
- Test the URL in a browser first
- Wait a few minutes if just deployed
